# 忍び日本語 Shinobi Nihongo

PWA pribadi untuk latihan kaiwa bahasa Jepang dari kegiatan sehari-hari.

- Frasa sopan (〜ます) + audio pelan/normal untuk shadowing
- Mode Kage, daftar Perlu diulang (maks 10 aktif), Hafal, streak 🔥
- Menu Kotoba dengan pola kaiwa, Kanji hari ini (61 kanji umum)
- Data & API key hanya tersimpan di perangkat (localStorage)

Pasang: buka di Safari → Share → Add to Home Screen.
